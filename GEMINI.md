# Gemini Code Assist Instructions

This document provides instructions for Gemini Code Assist on how to interact with this project.

## Project Overview

This is a React application built with Vite and TypeScript. It uses Tailwind CSS for styling.

## Development

### 1. Install Dependencies

To install the project dependencies, run:

```bash
npm install
```

### 2. Run the Development Server

To start the development server, run:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` by default (Vite's default port).

### 3. Build for Production

To create a production build, run:

```bash
npm run build
```

The output will be in the `dist` directory.

### 4. Linting

To check the code for linting errors, run:

```bash
npm run lint
```

### 5. Preview Production Build

To preview the production build locally, run:

```bash
npm run preview
```
